# 로컬 파일 안내

최초 정리일: 2026-11-17 · 최종 안내 검토일: 2026-11-21

프로젝트 위치는 `voice-caption` 폴더입니다. 다른 개인 폴더는 정리 대상에 포함하지 않았습니다.

| 위치 | 내용 |
|---|---|
| `README.md` | 프로젝트 입구, 친구용 설명서 링크 |
| `docs/친구용-사용설명서.md` | GitHub에서 읽는 초보자용 설명서 |
| `docs/친구용-사용설명서.html` | 브라우저로 여는 초보자용 설명서 |
| `read.md` | 제작자용 빌드·기술 안내 |
| `voice_caption/` | 프로그램 소스 |
| `tests/` | 자동 테스트 |
| `packaging/`, `scripts/` | Windows 실행 파일·소스 ZIP 제작 설정 |
| `release/` | Windows 실행용 ZIP, 소스 ZIP과 각 SHA-256을 보관하는 위치. GitHub 소스 커밋에서 제외 |
| `release/친구용-안내/` | HTML 설명서와 예시 이미지. 실행 프로그램은 미포함 |
| `release/archive/` | 정리 전에 만든 소스 ZIP 보관 |

개발 중 생성한 `.venv-ui`(macOS UI 검사 전용 가상 환경)와 `__pycache__`는 재생성 가능한 파일이므로 정리했습니다. 프로그램 소스·테스트·기존 배포 ZIP은 보존했습니다. UI 검사가 필요하면 새 가상 환경에 PySide6를 설치해 실행하세요.

GitHub 저장소: https://github.com/QmdQkdQHd/voice-caption (공개)

기존 GitHub 커밋 이력을 로컬 `.git`에 연결했습니다. `origin`은 위 저장소이며 브랜치는 `main`입니다. 연결된 GitHub 도구로 커밋하고 로컬도 같은 커밋으로 동기화했습니다. Git CLI로 직접 push하려면 별도 정상 인증이 필요할 수 있습니다.

친구에게 전달할 실행 파일은 `release/VoiceCaption-0.2.0-windows-x64.zip`입니다. Windows 빌드가 완료되었으며, 제작자가 GitHub Actions의 `VoiceCaption-windows-x64` 아티팩트에서 프로그램 ZIP을 내려받아 이 위치에 보관합니다. 소스 ZIP이나 설명서 ZIP만으로는 프로그램을 실행할 수 없습니다.

GitHub Actions에서 받는 바깥 ZIP에는 프로그램 ZIP이 다시 들어 있습니다. 제작자는 안쪽 `VoiceCaption-0.2.0-windows-x64.zip`을 친구에게 전달하면 됩니다. 실제 Windows 10/11 PC의 오디오·게임 동작은 아직 별도 확인이 필요합니다.
