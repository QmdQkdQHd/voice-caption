## Windows 실행 파일 빌드 검증

첫 Windows 실행 파일 빌드가 성공했습니다.

- 빌드 기록: [Build Windows app #1](https://github.com/QmdQkdQHd/voice-caption/actions/runs/43944802001)
- 검증한 커밋: `b0b327c9d839a2e68ee33aec12d7a70e57ea6d9a`
- 환경: GitHub Actions `windows-2022` / Windows Server 2022, Python 3.11 x64
- 자동 테스트: 18개 통과
- 패키징된 EXE: 주요 라이브러리 import, 포함된 Silero VAD 로딩, spawned 자식 프로세스와 IPC 검사 통과
- 패키징된 EXE의 UI 시작 검사 통과
- 프로그램 ZIP 생성 완료: `VoiceCaption-0.2.0-windows-x64.zip`, 약 366 MB(349 MiB), 별도 SHA-256 파일
- GitHub Actions 아티팩트: `VoiceCaption-windows-x64`. 공개 Release는 아직 없음

이 결과는 Windows Server 2022의 빌드·번들 실행 검사입니다. 실제 Windows 10/11의 오디오 장치·게임 위 자막 표시·OCR 정확도를 입증하지는 않습니다. 첫 빌드에서는 실제 언어 모델을 내려받아 음성 인식과 번역을 끝까지 수행하는 통합 검사를 하지 않았습니다. 후속 검사 결과가 확인되면 이 기록에 추가합니다.

## 소스 패키지 검증

- 소스 ZIP 테스트로 키 파일·가상 환경·설정·모델·음성 기록 제외 및 SHA-256 일치를 확인했습니다.
- Python 소스와 빌드 스크립트 구문 검사, PyInstaller spec 구문 검사를 통과했습니다.
- `VoiceCaption-0.2.0-source.zip`은 개발용이며 실행 파일을 포함하지 않습니다.

## 앞서 macOS 개발 환경에서 확인한 내용

- Python 3.14: 핵심 로직 및 프로세스 테스트 17개 통과. 대기열 최신 음성 유지, 화자 반복 관측/충돌/공백 처리, 번역 모델 경로 탐색, 설정 저장과 범위 제한, 다중 모니터 영역 파싱. 추가로 강제 중지 후 3회 재시작과 자식 프로세스 잔존 여부, 비정상 종료 코드 전달 확인.
- Python 구문 컴파일 통과.
- macOS Python 3.9.6 + PySide6 6.8.3: UI 시작/종료 검사 통과. 이 Python은 UI 검사에만 사용했으며 전체 앱 권장 환경은 Windows Python 3.11.
- Qt offscreen: 자막 크기·폰트 크기·불투명도 설정, 클릭 통과 플래그 전환, 숨김/표시, 설정 저장 검사. 렌더링 이미지 생성 및 육안 검토.
- 재실행한 UI의 글자 크기·불투명도·창 크기 복원 및 비 Windows 환경에서 캡처 시작 차단 확인.
- 개선 회귀 검증: 짧은 발화의 무음 종료와 사전 버퍼, 연속 소리의 최대 길이, 자막별 만료, 느린 번역 중 다음 입력 수용, 중지 후 결과 차단, 늦은 API 결과 폐기, 원문 대체 표시, 실제 spawn 프로세스의 강제 종료와 마지막 오류 전달.
- 외부 API 실제 호출, 모델 다운로드/추론, 오디오 녹음, 실제 화면 캡처는 이 검증에서 수행하지 않음.

Qt offscreen 검사는 Windows의 실제 최상위 창·클릭 통과·게임 위 표시 동작을 입증하지 않습니다. Windows 빌드 환경의 의존성 설치와 번들 검사는 위 별도 기록을 참고하세요.

## 실제 Windows 10/11 PC에서 남은 확인 항목

1. Windows 10 64비트 + Python 3.11에서 `install-windows.cmd`가 성공하는지 확인.
2. 영어 → 한국어 `tiny` 모델 준비 후 네트워크를 끊고 로컬 번역 확인.
3. 실제 출력 장치 선택, 30초 이상의 대화 캡처, 무음에서 잘못된 자막 발생 여부 확인.
4. 장치 분리, 중지·재시작, 실행 중 창 닫기가 안전하게 완료되는지 확인.
5. 테두리 없는 창 모드에서 자막 최상위 표시와 클릭 통과 확인.
6. 100%/150% 화면 배율 및 여러 모니터에서 위치 저장·복원 확인.
7. 디스코드와 발로란트 각각 화면 영역·발화 색상 조정 후 한 명/두 명 동시 발화 확인.
8. 게임 중 CPU 사용률, FPS 변화, 발화 종료부터 자막 출력까지 지연을 측정. CPU 모델과 함께 기록.
9. API를 명시적으로 켠 경우에만 텍스트 전송되는지, 키 누락·한도 초과 시 원문을 표시하는지 확인.

## 현재 한계와 후속 개선

- 범용 자동 화자 인식이 아닌 사용자 지정 영역·색상 기반 OCR 프로토타입. 실제 게임 검증과 프리셋 필요.
- 무음 기준으로 구간을 분리하지만 지속적인 게임 소리는 최대 길이에서 잘림. 학습 기반 실시간 VAD와 경계 중복 처리 개선 필요.
- 출력 장치 하나만 캡처. 앱별 캡처, 동시 마이크 입력, 게임 효과음 제거는 미구현.
- 모델 다운로드는 완료까지 기다려야 창을 닫을 수 있음. 음성 처리 중지는 별도 프로세스 정리로 개선했으나 실제 Windows 드라이버의 재시작은 검증 필요.
- 실행 파일 패키징은 완료. 단축키, 트레이, 프로필 여러 개 저장은 미구현.
- 모델/패키지 버전의 재현 가능한 잠금은 Windows 통합 검증 후 진행할 것.
